# Componentes

Spotlight de Aceternity UI, por Manu Arora. Fuente oficial: https://ui.aceternity.com/registry/spotlight.json. Componente conservado en src/components/ui/spotlight.tsx; animación en el CSS global para Tailwind 4.

## Tipografías locales

Extraídas de los ZIP aportados en `fonts/`. Se distribuyen sin modificar junto con sus licencias SIL OFL 1.1 en `public/fonts/`.

- Maple Mono: Copyright 2022 The Maple Mono Project Authors. Texto, títulos e interfaz. Variantes variable normal e italic.
- JetBrains Mono: Copyright 2020 The JetBrains Mono Project Authors. Bloques de código y etiquetas técnicas. Variante variable normal.
- WindSong: Copyright 2013 The WindSong Project Authors. Acentos manuscritos y marca. Variante Regular.

## Decoración ASCII

El ojo ASCII se genera a partir de la imagen del logotipo de Nmap aportada por el usuario (`public/images/nmap-eye-reference.png`). Solo se muestrea la zona del ojo, excluyendo las letras y el fondo exterior. Referencia del proyecto original: https://nmap.org/images/. No implica afiliación con Nmap.
