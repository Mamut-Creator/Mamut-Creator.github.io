# Ejemplos locales

Estas máquinas son ficticias y no se publican en el portfolio. Sirven para consultar la estructura de carpetas, imágenes, enlaces y código. Para ver Nebula en desarrollo, copia su carpeta a `src/content/writeups/nebula/`; retírala antes de publicar contenido real.

La carpeta `templates/maquina/` es la base recomendada para una máquina nueva. `src/lib/site.ts` contiene la identidad del portfolio.
