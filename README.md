# Jorge Romero · Bitácora

Mi portfolio de ciberseguridad: un espacio para documentar máquinas, explorar técnicas y dejar constancia de lo aprendido.

**[Visitar el portfolio →](https://mamut-creator.github.io/)**

## Aprender y documentar

Cada write-up busca explicar el recorrido: las primeras pistas, las decisiones, los intentos y las conclusiones. El objetivo es entender el proceso y construir notas a las que pueda volver.

- Reconocimiento y enumeración de servicios.
- Análisis de vulnerabilidades y caminos de acceso.
- Escalada de privilegios y aprendizajes.
- Capturas y comandos junto a su explicación.

## El proyecto

Una web estática construida con **Astro**, **Aceternity UI** y **Tailwind CSS**, con artículos en Markdown y una carpeta de imágenes por máquina. Incluye búsqueda, filtros, visor de capturas con zoom y bloques de código resaltados.

GitHub Actions comprueba y publica el sitio automáticamente en GitHub Pages.
