# Bitácora de write-ups

Abre `dist/index.html` en el navegador para ver el proyecto. No necesita instalación ni compilación.

Para añadir una máquina, copia una entrada en `dist/data.js` y cambia sus campos: nombre, plataforma, dificultad (`Fácil`, `Media` o `Difícil`), sistema operativo, etiquetas, introducción y secciones. Cada sección contiene un título, un párrafo y, opcionalmente, un comando. Las tres entradas incluidas son ejemplos ficticios: elimínalas cuando tengas contenido propio.

La búsqueda filtra nombre, plataforma, sistema, dificultad y etiquetas; la tecla `/` lleva al buscador. Haz clic en una máquina para abrir su artículo y usa Escape para cerrarlo.

Para incluir imágenes o contenidos más ricos será necesario ampliar la plantilla; esta primera versión está pensada como base sencilla.
